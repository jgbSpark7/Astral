✦ Astral - Controller Utility

Astral by LuminarCore is a small utility program that allows for more control for gamers who want more.

⚠️ Note on Controller Support: At the moment, Astral is only compatible with PS4, PS5, and Marius Board controllers. No support for other controller models exists at the moment.

You can overclock your controller, test your buttons and inputs and see how well sticks perform with linearity tests, circularity tests and deadzone testing. All features are intended to be clean, simple and clutter-free.

⭐ Features
• Controller overclocking
• Button & input testing
• Linearity testing
• Circularity testing
• Deadzone testing
• Clean, customizable color themes
• And many others coming in the future

The app will keep getting updated, with new features, improvements, and additions.
